# Global Household AIOps

A production-oriented MLOps and GenAIOps platform built around the
Global Household Financial Health dataset.

## Project Goal

The project demonstrates how to take machine learning and generative AI
from experimentation to a repeatable, deployable, observable and
maintainable production system.

## Core Areas

### MLOps

- Data validation
- Feature engineering
- Model training
- Experiment tracking
- Model evaluation
- Model registry
- CI/CD
- Deployment
- Monitoring

### GenAIOps

- LLM and SLM orchestration
- RAG
- Prompt engineering
- Prompt versioning
- GenAI evaluation
- Quality and safety
- Observability
- Cost monitoring
- Performance optimization

### Engineering

- Python
- Git/GitHub
- GitHub Actions
- Docker
- Infrastructure as Code
- Bicep
- Azure ML
- Microsoft Foundry
