# Global Household Financial Dynamics Dataset

## Overview

The dataset contains household-level financial information across multiple countries and cities.

The dataset contains approximately 5,000 household records.

Each record represents one household.

## Main Areas

The dataset captures:

- Household demographics
- Number of earners
- Income
- Estimated taxes
- Monthly expenses
- Monthly savings
- Geographic information

## Analytical Purpose

The dataset is used to analyse:

- Household financial health
- Savings behaviour
- Spending behaviour
- Country-level differences
- Financial vulnerability
- Household financial segments
- Machine-learning classification
